# /refactor — Cursor Command

Switch the workspace to Refactor Mode.

## Purpose
- Aligns Cursor with `0-agents/mode/refactor.md`
- Focuses on safe, minimal, and well-documented structural/code refactors

## When to Use
- Renaming, moving files, or restructuring modules
- Improving readability without changing behavior
- Extracting helpers, consolidating duplicates, enforcing conventions

## Rules
- Follow `0-agents/workflows/development-rules.md`
- Update `INDEX.md` and `8-governance/changelog.md` after structure changes
- Consult `@docs-guardian` for documentation impacts
- Do not introduce functional changes unless explicitly scoped

## Handoff
- End with the orchestration handoff per `0-agents/workflows/orchestration-protocol.md`
