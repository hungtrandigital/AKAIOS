# Executive Docs — Central Overview

## Purpose

Provide a single entry point for business owners to view project overview, executive summaries, and jump to detailed departmental documents. Centralize high-level narratives while each department maintains detailed docs in its own folder.

## Ideas Status Table (update every change)

| Item | Status | Priority | Stage | Owner | Last Updated | Link |
| --- | --- | --- | --- | --- | --- | --- |
| executive-summary | Draft | High | Draft / In Review / Ready / Archived | @owner | YYYY-MM-DD | [executive-summary.md](executive-summary.md) |

**How to use this table:** One row per executive-level doc. Stages: `Draft` (initial narrative), `In Review` (feedback), `Ready` (approved executive view, synced with departmental links), `Archived` (superseded). Update `Last Updated` on every status/content change; create new docs only after docs-guardian approves placement/naming. **Sort rows newest-first by `Last Updated` so the latest executive view is at the top.**
