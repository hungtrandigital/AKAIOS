# Job Description — Senior Backend Engineer (JD ID: OPS-TASK-001)

**Level/Band:** IC4 (Senior)  
**Department/Team:** Engineering → Platform  
**Location/Type:** Remote-first (±3h PT preferred)  
**Reports To:** Head of Engineering  
**Employment Type:** Full-time  
**Parent Epic:** PRD-EPIC-ENG-SCALE  
**Registry Link:** `../tracking/registry.md` (OPS-TASK-001)

## Mission (3-5 bullets)
- Build and scale backend services that support current roadmap growth targets
- Improve reliability and performance of core APIs and data flows
- Raise engineering quality bar via reviews, standards, and observability improvements

## Responsibilities (5-10 bullets)
- Design, build, and ship backend services (Python/Node/Go) with clear SLIs/SLOs
- Own API and data model evolution in collaboration with Product and Frontend
- Improve reliability via better monitoring, alerting, and incident response runbooks
- Optimize performance (profiling, caching, query tuning) for latency and throughput targets
- Contribute to security and compliance practices (authN/Z, secrets, logging)
- Mentor peers through code reviews and pairing; document patterns and playbooks

## Requirements — Must-Have
- 5+ years backend experience shipping production services
- Strong with one of: Python/Go/Node; comfortable with SQL/NoSQL data stores
- Experience with cloud (AWS/GCP/Azure) and containerization (Docker/K8s)
- Solid system design fundamentals; able to reason about scaling, reliability, costs
- Clear written and verbal communication; collaborates across Product/Design

## Requirements — Nice-to-Have
- Experience with event-driven architectures and queues/streams
- Exposure to observability stacks (OpenTelemetry, Prometheus/Grafana)
- Security-minded: authN/Z patterns, secrets management, least-privilege access
- Prior startup experience; comfortable with ambiguity and speed

## Success Metrics (see `../tracking/metrics-glossary.md`)
- Time to first meaningful contribution: <3 weeks; independent shipping by week 6
- Service reliability: meets team SLOs (uptime/latency/error budgets)
- Code quality: PR review signals, defect rate, on-call quality
- Collaboration: positive peer feedback; drives docs and knowledge sharing
