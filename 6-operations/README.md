## Lifecycle & Structure

**This Folder as Working Document:**
- `strategy.md` is the single source of truth for how we operate; updated quarterly (Q1, Q2, Q3, Q4)
- `tracking/registry.md` is the live list of initiatives and metrics; updated monthly
- `history/changelog.md` tracks major changes; entries added when they occur
- Templates in `templates/` are copied per use (hiring-plan-[role]-[YYYY-MM].md, onboarding-[employee]-[YYYY-MM-DD].md, jd-[role]-[YYYY-MM].md)

**Versioning & Archival:**
- Completed hiring plans and onboardings archived to `archives/` with hiring summary or employee success metrics
- Quarterly snapshots of `strategy.md`, `registry.md`, and `changelog.md` archived to `archives/YYYY-QX/` (e.g., `archives/2025-Q4/ops-strategy-snapshot.md`)
- Keeps active folder lightweight; preserves history for reference

**Scale Rules:**
- **Active Initiatives:** Keep ≤10 active operational initiatives (hiring, legal, vendor, culture, process)
- **Parking Lot:** Use parking lot section in `strategy.md` for paused/shelved work; review monthly
- **Hiring Cadence:** Groom open roles weekly; resequence by priority monthly; archive completed hires quarterly
- **Vendor Consolidation:** Target <30 active vendors; review quarterly for overlaps and cost reduction
- **Metrics Update:** Review key metrics monthly in `registry.md`; archive actual vs. target snapshot quarterly

## Tracking & Reports

**Dashboards & Metrics:**
- `tracking/registry.md` — Active initiatives (OPS-TASK-XXX), headcount metrics, hiring pipeline, vendor status
- `tracking/metrics-glossary.md` — Definitions for turnover, time-to-hire, cost-per-hire, burn, compliance status, vendor count
- Healthy benchmarks for SaaS in metrics glossary (e.g., <10% turnover, 4-6 week time-to-hire, <30% headcount burn)

**Work Item Assignment:**
- OPS-TASK-XXX: All operational initiatives (hiring, legal, vendor, culture, process)
- Parent epic: Each task declares parent PRD-EPIC-XXX if product-related
- Cross-domain links: OPS-TASK-XXX → Marketing (MKT-TASK-XXX), Finance (FIN-TASK-XXX)

**Workflow:**
1. **Quarterly Strategy Update** — Review `strategy.md`; define next 12 months hiring, culture, compliance, infrastructure goals
2. **Monthly Registry Review** — Update `registry.md` with active initiatives + latest metrics; review Parking Lot
3. **Weekly Hiring Groom** — Review candidate pipeline; update hiring plans; prioritize open roles
4. **Monthly Manager Calibration** — Performance discussions, compensation, promotions
5. **Quarterly Compliance Check** — SOC 2, data protection, audit readiness; update `strategy.md` compliance section
