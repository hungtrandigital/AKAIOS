## Pre-Arrival (Days -14 to -1)

**Hardware & Access**
- [ ] Laptop ordered (Mac/Windows spec: [model])
- [ ] Phone & SIM ordered (if applicable)
- [ ] Desk/workspace assigned
- [ ] VPN/WiFi credentials prepared
- [ ] Email account created
- [ ] Slack account created
- [ ] GitHub / Dev environment access provisioned
- [ ] Notion / CMS access granted
- [ ] All third-party tool access (Jira, Linear, HubSpot, etc.)

**Documentation & Onboarding Materials**
- [ ] Welcome email sent (w/ start date, logistics, what to bring)
- [ ] Company handbook emailed (NDA, code of conduct, benefits)
- [ ] Organizational chart provided
- [ ] Onboarding video/orientation link sent
- [ ] Team introductions email sent
- [ ] Commute & parking info (if applicable)
- [ ] IT onboarding guide sent

**Logistics**
- [ ] Office keys/badge ordered (if in-office)
- [ ] Parking spot assigned
- [ ] Desk setup (monitor, keyboard, chair, etc.) ready
- [ ] Welcome package prepared (if applicable)

---

## Day 1

**Morning**
- [ ] Employee arrives on time
- [ ] Manager meets employee, gives office/workspace tour
- [ ] IT hands over laptop, peripherals, phone
- [ ] Manager ensures WiFi/VPN login works
- [ ] Employee sets up workspace (desk, equipment)

**Orientation**
- [ ] Company mission, values, culture video/walkthrough (30 min)
- [ ] Manager 1:1 — role expectations, team structure, first week plan (45 min)
- [ ] Buddy introductions — team lunch or coffee (social)
- [ ] System access verification — email, Slack, GitHub, internal tools
- [ ] Handbook review — NDA/IP/confidentiality/code of conduct (sign-off required)

**Documentation**
- [ ] Employee handbook signed off
- [ ] Tax forms (I-9, W-4, state) submitted
- [ ] Emergency contact info collected
- [ ] Direct deposit enrollment
- [ ] Benefits enrollment (if applicable)

**Accounts & Tools Setup**
- [ ] Slack: [Company workspace] joined
- [ ] Email: Forwarding rules set up, signature added
- [ ] GitHub: [Org/repo] access granted; intro to dev environment
- [ ] Notion: [Workspace] access granted
- [ ] Calendar: First week meetings blocked; recurring team meetings added
- [ ] Password manager: Company vault access provided (LastPass, 1Password, etc.)

**Lunch**
- [ ] Team lunch or manager 1:1 lunch (informal introduction)

---

## Week 1

**By End of Day 1 (Close of Business)**
- [ ] All hardware working (laptop, phone, peripherals)
- [ ] All accounts accessible (email, Slack, GitHub, internal tools)
- [ ] Employee feels welcome and oriented

**Monday–Friday**

**Daily Standup / Check-in (Daily)**
- [ ] Manager or buddy checks in (10-15 min) — How's it going? Questions? Blockers?

**Technical Onboarding (Days 1-3)**
- [ ] Dev environment setup complete (repo cloned, dependencies installed, local build works)
- [ ] Product/codebase walkthrough (2 hours with tech lead or senior team member)
- [ ] First task assigned — something small and low-risk to learn the repo

**Team Introductions (Days 1-5)**
- [ ] Meet each direct team member (1:1 coffee or Slack pairing)
- [ ] Meet key cross-functional partners (Product, Design, Marketing, etc.)
- [ ] Join key Slack channels (general, team-specific, random, updates)

**Policy & Process Review (Day 1-2)**
- [ ] Time off / vacation policy explained
- [ ] Expense policy & reimbursement process
- [ ] 1:1 cadence established (weekly 30min preferred)
- [ ] Performance review cycle explained (annual? quarterly?)
- [ ] Communication norms (async? all-hands frequency? stand-up?)

**Learning & Documentation (Days 1-5)**
- [ ] Product demo (30 min with PM or team lead)
- [ ] Company strategy overview (15 min with leadership)
- [ ] Existing team rituals scheduled: retros, planning, all-hands, etc.
- [ ] Company wiki / design docs / architecture docs shared
- [ ] Role-specific docs reviewed (runbooks, playbooks, etc.)

**By End of Week 1**
- [ ] All accounts fully operational
- [ ] First coding task in progress or completed (if technical role)
- [ ] Understands team structure and reporting relationships
- [ ] Has met core team members
- [ ] Feels comfortable asking questions

**Week 1 Checkpoint (Manager 1:1)**
- [ ] How are you settling in?
- [ ] Any blockers or missing information?
- [ ] First task progress — on track?
- [ ] Do you feel welcomed and supported?
- [ ] Next week priorities?

---

## Month 1 (Weeks 2-4)

**Weeks 2-3: Ramping Up**
- [ ] Continue daily check-ins (can decrease frequency to 2-3x week if going well)
- [ ] First PR/code contribution shipped (if technical)
- [ ] Attending all team meetings and standup
- [ ] Shadowing senior team members on key tasks
- [ ] Contributing to 1-2 medium-complexity tasks
- [ ] Reading company docs, customer feedback, roadmap

**By Mid-Month (Week 2-3 Checkpoint)**
- Manager 1:1 (30 min):
  - [ ] How's the first 2 weeks felt?
  - [ ] Any surprises or culture shocks?
  - [ ] Are learning materials clear?
  - [ ] Any skill gaps we need to address?
  - [ ] Feel comfortable in role yet?
  - [ ] Team support adequate?

**Week 3-4: Independent Contribution**
- [ ] Completing tasks with minimal guidance
- [ ] Pair-programming or code-review participation
- [ ] Attending customer calls / user research (if applicable)
- [ ] Contributing to team discussions (retrospectives, planning)
- [ ] Exploring codebase, asking architectural questions

**By End of Month 1 (Week 4 Full Review)**
- Manager 1:1 (45 min):
  - [ ] Month 1 overall assessment: Are they ramping well?
  - [ ] Technical progress: Can they ship code independently yet?
  - [ ] Cultural fit: Vibing with team?
  - [ ] Skill gaps identified: What to work on in Month 2-3?
  - [ ] Strengths: What are they already great at?
  - [ ] Concerns: Any flags?
  - [ ] Set Month 2 goals (2-3 focus areas)
  - [ ] Schedule 30/60/90 day reviews

**By End of Month 1 (Employee Checklist)**
- [ ] Shipped at least 1 meaningful contribution (PR, project, initiative)
- [ ] Knows who to ask for help
- [ ] Understands team rituals and communication norms
- [ ] Has built initial relationships with team members
- [ ] Can navigate company systems and processes
- [ ] Feels confident asking questions
- [ ] Received positive feedback from at least 2 team members

---

## 30-Day Review

**Timing:** End of Week 4  
**Duration:** 45-60 minutes  
**Participants:** Manager + HR (optional)

**Manager Assessment:**
- Performance on assigned tasks: On track / Ahead / Behind
- Code quality (if applicable): High / Average / Needs improvement
- Communication: Clear / Developing / Needs work
- Collaboration: Strong / Average / Needs development
- Cultural fit: Strong / Good / Needs nurturing
- Overall ramp trajectory: On track / Ahead / Behind

**Employee Self-Assessment:**
- How do you feel about your first month?
- What's going well?
- Where do you need more support?
- Are your expectations being met?
- Any concerns or red flags?

**Outcomes:**
- [ ] Probation period (if applicable) on track
- [ ] Confirm second month focus areas
- [ ] Agree on 60-day review criteria
- [ ] Identify any skill gaps to address

**Follow-up Actions:** [Notes]

---

## 60-Day Review

**Timing:** End of Week 8  
**Duration:** 45 min  
**Participants:** Manager + HR (optional)

**Progress Check:**
- Have 30-day goals been met?
- Is employee becoming independent contributor?
- Quality of work: Improving / Consistent / Declining?
- Team integration: How's the fit?
- Any emerging concerns?

**Skills & Growth:**
- What has employee learned?
- What are their strengths?
- Where do they need development?
- Recommend any training or mentoring?

**Outcomes:**
- [ ] Confirm 90-day review goals (finalize probation period)
- [ ] Discuss next quarter priorities and role expansion
- [ ] Set up 90-day full review

**Follow-up Actions:** [Notes]
