# Refactoring

## Purpose

This directory contains refactoring plans and analysis created by **Refactor Mode**. Use Refactor Mode when you have an existing project and want to adopt Factory standards without major restructuring.

## Contents

- **[plan.md](plan.md)** - Main refactoring plan with structure mapping
- **[implementation-plan.md](implementation-plan.md)** - Detailed implementation plan with tasks
- **[structure-analysis.md](structure-analysis.md)** - Analysis of current project structure
- **[structure-mapping.md](structure-mapping.md)** - Mapping between current structure and Factory standards

## When to Use

Use Refactor Mode when:
- ✅ You have an existing project with source code
- ✅ You want to adopt Factory processes without major restructuring
- ✅ You want to gradually improve organization and documentation
- ✅ You want to preserve your current structure as much as possible

## How It Works

1. **Refactor Mode** analyzes your current project structure
2. Creates mapping between your structure and Factory standards
3. Generates refactoring plan with suggested actions
4. Updates agents to work with your existing structure
5. Creates missing documentation and folders
